Propositional Logic

A quick reviewer: learn, flip, play.

What is logic?

Logic is the study of reasoning: whether an argument is correct or not. It looks at how statements relate to each other, not at what any single statement is about. Propositional logic works at the level of whole sentences.

Proposition: a declarative sentence that is either true or false, but not both.

Commands, questions, exclamations and open sentences (with unknown variables) are not propositions. Letters like p, q, r, s are propositional variables. In a truth table, T is a true proposition and F is a false one.

Compound propositions

Simple true-or-false sentences are basic propositions. Joining them with connectives builds compound propositions. A truth table lists the value of a proposition for every possible combination of its variables.

The five basic connectives

Notation: not ¬, and ∧, or ∨, if–then →, if and only if ↔. A sixth, exclusive or, is ⊕.

Examples

Negation

“Michael’s PC runs Linux” becomes “Michael’s PC does not run Linux.”

Conjunction

p: 7 is an integer (T). q: 5 is less than 3 (F). So p ∧ q = T ∧ F = F.

Disjunction

p: 2 is an integer (T). q: 3 is greater than 5 (F). So p ∨ q = T ∨ F = T.
p: 2 is an odd integer (F). q: 5 is less than 3 (F). So p ∨ q = F ∨ F = F.

Inclusive vs. exclusive or

Inclusive: “Students who took calculus or computer science can take this class.” Both is fine.
Exclusive: “…calculus or computer science, but not both.” Exactly one.

Practice

Build the truth table for each:

1. (p ∨ q) → (p ⊕ q)
2. (p ⊕ q) → (p ∧ q)
3. (p ∨ q) ⊕ (p ∧ q)
4. (¬p ∧ q) ↔ (p ∨ q)
5. (¬p ∨ q) → (p ↔ q)

Conditional: p → q

“If p, then q.” It is false only when p is true and q is false. Here p is the hypothesis (antecedent, premise) and q is the conclusion (consequence).

Example: p: Maria learns discrete mathematics. q: Maria will find a job. Then p → q reads “If Maria learns discrete mathematics, then she will find a job.”

Converse: If you are good in Logic, then you are good in Mathematics.
Contrapositive: If you are not good in Logic, then you are not good in Mathematics.
Inverse: If you are not good in Mathematics, then you are not good in Logic.

Tricky wording

“The home team wins whenever it is raining.” Let r: it is raining, w: the home team wins. The statement is r → w.
Converse: If the home team wins, then it is raining.
Contrapositive: If the home team does not win, then it is not raining.
Inverse: If it is not raining, then the home team does not win.

Biconditional: p ↔ q

“p if and only if q.” True when p and q have the same truth value, false otherwise. It has the same truth values as (p → q) ∧ (q → p).

Also: “p is necessary and sufficient for q” and “if p then q, and conversely.” Example: “You can take the flight if and only if you buy a ticket.”
