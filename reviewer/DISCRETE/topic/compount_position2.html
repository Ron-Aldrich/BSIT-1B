Construction of Truth Table

Part 2: build the table of a compound proposition, column by column.

How to build a truth table

A truth table of a compound proposition lists its truth value for every possible combination of truth values of its variables. You build it one small piece at a time.

  1. Count the variables (n). The table needs 2n rows.
  2. Fill the variable columns using the pattern below.
  3. Add one column for each smaller part of the expression. Work from the inside out: negations first, then the parts in parentheses.
  4. Fill each column using the rule of its connective.
  5. The last column is the whole expression. Read it to see what kind of proposition it is.

Filling the variable columns

The first variable is T for the first half of the rows and F for the second half. Each next variable uses blocks half as long. The last variable alternates T, F, T, F.

2 variables (4 rows)

p: 2 T, 2 F. q: T, F, T, F.

3 variables (8 rows)

p: 4 T, 4 F. q: 2 T, 2 F, 2 T, 2 F. r: T, F alternating.

4 variables (16 rows)

p: 8 T, 8 F. q: 4 T, 4 F, 4 T, 4 F. r: 2 T, 2 F repeated. s: T, F alternating.

Rules to remember

What do I solve first?

Parentheses, then ¬, then ∧, ∨, →, ↔. See the Order tab for the full rule and many examples.

Reading the last column

Tautology: every row is T.
Contradiction: every row is F.
Contingency: a mix of T and F.

What to solve first

When an expression has several connectives, work in this order, from first to last:

  1. Parentheses ( ), innermost first
  2. Negation ¬
  3. Conjunction ∧
  4. Disjunction ∨
  5. Conditional →
  6. Biconditional ↔
Give every step its own column. The step you do first gets the column closest to the variables, and the last step is the final column.

Good to know

¬ only touches what is right after it. ¬p ∧ q means (¬p) ∧ q. To negate a whole group, write ¬(p ∧ q).
Chains like p → q → r are unclear without parentheses, so always write them as (p → q) → r or p → (q → r).
When in doubt, add parentheses. A textbook or teacher may group differently, and parentheses always settle it.
