Construction of Truth Table

Part 1: connectives, number of rows, and worked examples.

Compound propositions

Compound proposition: propositions that are combined and connected by logical connectives: negation, conjunction, disjunction, conditional and biconditional.
Truth table: a table that shows all the possible truth values of each expression in a compound proposition.

To find the truth value of a compound proposition, you use a truth table. That is why you must master the definition of each connective: you apply it to every part of the expression.

How many rows?

A single proposition p can only be true or false, so it has 2 options. Every extra variable doubles the number of rows. For n variables, the table needs 2n rows.

Filling the variable columns

Use T for true and F for false. The first variable is T for the first half of the rows and F for the second half. Each next variable uses blocks half as long, and the last variable alternates T, F, T, F.

2 variables (4 rows)

p: 2 T, 2 F. q: T, F, T, F.

3 variables (8 rows)

p: 4 T, 4 F. q: 2 T, 2 F, 2 T, 2 F. r: T, F alternating.

Break it into parts

  1. Count the variables and find the number of rows (2n).
  2. Fill the variable columns.
  3. Give each part of the compound proposition its own column, and also any negation you need.
  4. Fill each column with the rule of its connective.
  5. Combine the parts in the final column. That column is the truth value of the whole compound proposition.

The five connectives

Notation: not ¬, and ∧, or ∨, if–then →, if and only if ↔.

Conditional p → q

Here p is the first proposition (hypothesis) and q is the second (conclusion). It reads "if p, then q". The only way it fails is T → F.
